# 使用说明

**简体中文** | [English](USAGE.en.md)

## 1. 适用范围

本工具用于把《心动小镇》客户端 `ScreenCapture` 目录中的加密截图批量还原为可正常打开的 JPG/PNG。它只读取你选择的源目录，解密结果只写入你另行指定的输出目录。

支持 Windows 10/11 x64。安装包已内置 WebView2 离线安装器，运行时不需要 Node.js、Rust、Python、OpenSSL，也不需要启动游戏或任何本地服务。

> 输入目录和输出目录不能相同，输出目录也不能位于输入目录内部。工具会拒绝这类设置。

## 2. 首次使用

1. 启动程序。若本机存在默认游戏目录，程序会尝试自动探测 `ScreenCapture`。
2. 确认“输入目录”。可以点击“选择目录”，也可以展开“最近使用”选择历史目录。
3. 指定“输出目录”。建议使用与源目录无关的独立空目录（下文以 `<OUTPUT_DIR>` 表示）。
4. 点击“扫描图片”。

扫描在后台线程执行，期间界面仍可浏览和取消；取消后保留已经发现的结果，不删除任何文件。扫描或解密期间不要切换目录，等任务结束或取消后再修改输入/输出设置。

界面只显示目录最后一级名称和最近目录别名，不显示完整用户目录；手动输入框使用密码遮罩。完整路径只在本机配置和原生文件选择器中出现，不写入日志、失败清单或界面。

### 可选择的输入层级

- `ScreenCapture` 根目录：递归扫描 `Photo`、`Limit`、`Draw`、`NoBgPhoto`、`Announcement` 等子目录。
- 单个子目录：例如只选择 `Photo` 或 `Draw`。输出仍保留该子目录层级，便于归档。

扫描只接受 `.jpg`、`.jpeg`、`.png`（扩展名不区分大小写）。其他文件不会进入列表。

## 3. 筛选与日期

列表展示文件名和相对路径（含目录）、拍摄时间、大小、日期来源和处理状态；文件类型可通过筛选条件查看和限定。

筛选条件：

- 目录：按相对目录筛选。
- 类型：按 JPG/PNG 筛选。
- 日期：今天、近 7 天、近 30 天、全部，或自定义起止日期。
- 文件名/路径关键字。

日期优先从文件名中的图片 ID 推算。该 ID 已通过本地样本对照验证为 **Windows FILETIME**（自 1601-01-01 UTC 起的 100 纳秒数），不是 Snowflake/Twitter 时间戳。无法解析或超出合理范围时回退到文件修改时间；“日期来源”列会显示“文件名时间”或“修改时间”。日期按本机本地时区计算，起止日期均包含当天。切换筛选条件不会清空已勾选项，底部会显示当前筛选可见数量与已选数量。

## 4. 选择图片

每行左侧有复选框，支持：

- 单选、多选；
- “全选全部”：选择本次扫描的全部图片；
- “反选全部”：反选本次扫描的全部图片；
- “全选结果”：选择当前筛选结果；
- “反选”：反选当前筛选结果；
- “清空”：清空全部选择。

勾选状态以图片 ID 为准，切换筛选后仍然保留。解密会处理**全部已选图片，包括被当前筛选隐藏的已选项**；选择栏会显示已选总数以及筛选外的已选数量。开始解密前请确认数量，避免把不需要的分辨率一起处理。

> 同一画面可能保存为不同分辨率的图片，数量与尺寸以实际文件为准。可使用文件名中的宽高后缀进行关键字筛选，只处理需要的版本，减少重复解密。

## 5. 批量解密

1. 勾选图片。
2. 选择重名策略：
   - **跳过**（默认）：输出位置已有同名文件时跳过，不覆盖。
   - **自动重命名**：生成 `名称 (1).jpg` 一类的新名称，绝不覆盖已有文件。
3. 选择并发数（1–8）。机械硬盘建议 2–4；SSD 可适当提高。
4. 点击“解密 N 张”（N 为已选数量）。

输出默认保留源目录层级，并根据解密后文件头输出正确的 `.jpg` 或 `.png` 扩展名。每个文件先写入同目录临时文件，落盘成功后再原子改名；失败或取消会清理临时文件，不留下半成品。

单个文件失败不会中断整批任务。失败原因会显示在行内并记入日志；任务结束后可导出失败清单（CSV，包含相对路径和原因代码，不含完整用户目录）。

### 取消与关闭

- 点击“取消任务”后，不再开始新文件；正在写入的文件会完成或清理临时文件后停止。
- 扫描或解密期间不要关闭输出目录所在磁盘；如需退出，先取消任务。
- 程序退出不会删除已成功输出的文件。

## 6. 日志

底部日志面板显示本次会话的扫描、筛选、解密、失败、更新事件。日志同时写入本机日志目录，按大小轮转。

- “打开日志目录”使用系统文件管理器打开，不显示路径。
- “导出日志”会另存为文本文件；目标已存在时不会覆盖。
- 日志不记录密钥、完整源目录、完整输出目录或图片内容。

## 7. 检查更新

程序启动时可按设置自动检查更新，也可点击“检查更新”手动检查。

1. 有新版本时显示版本号、更新说明和下载进度。
2. 下载完成后，安装包会先经过签名校验。
3. 更新准备完成后，点击“重启并完成更新”使新版本生效；用户配置、最近目录和筛选偏好保留。
4. 检查失败、断网或更新服务器不可用不会影响当前版本使用。

这里的“热更新”指桌面应用版本更新，不会在运行中替换程序代码。

## 8. 常见问题

**扫描结果为 0**

- 确认选择的是 `ScreenCapture` 或其子目录；单独选择无关目录不会猜测。
- 确认文件扩展名是 `.jpg`、`.jpeg` 或 `.png`。
- 若目录被游戏占用或权限不足，日志会记录跳过数量。

**解密后图片打不开**

- 只有游戏生成的加密截图才可以解密；已被其他工具改写或截断的文件会失败。
- 查看失败清单中的原因代码，并保留原文件用于复现。

**输出目录被拒绝**

- 输出目录不能等于输入目录，也不能位于输入目录内部。
- 不允许写入游戏安装目录或其他受保护位置。
- 输出目录与输入目录通过符号链接、junction 指向同一位置时同样会被拒绝。

**中文路径或超长路径失败**

- 工具按 Unicode 路径处理中文目录；源文件名本身不会被改写。
- 若输出路径超过系统限制，请缩短输出根目录或启用 Windows 长路径支持；失败会在日志和失败清单中记录，不会留下半成品。

**安装后无法启动**

- 安装包内置 WebView2 离线安装器；若系统策略阻止安装，请让管理员允许 Microsoft Edge WebView2 Runtime。
- Windows 10 需 x64 且已安装系统更新；不支持 32 位系统。

**杀毒软件拦截**

- 未购买代码签名证书的构建可能触发 SmartScreen 提示。请核对 Release 页面提供的 SHA-256 与签名，不要从第三方转载站下载。

## 9. 数据与隐私

- 原图只读，工具不会修改、移动或删除源文件。
- 输出只写入你选择的输出目录。
- 配置保存在本机 Tauri 配置目录；最近目录保存为不透明别名，界面按别名展示。
- 日志和失败清单会做路径脱敏。
- 游戏解密材料只在构建时注入，不显示在界面、不写入日志、不提交到 Git。发布二进制仍可能被有能力的人提取，因此它用于兼容性，不应被当作额外的访问控制。
