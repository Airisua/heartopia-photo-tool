# 验收证据目录

只存放可公开、已脱敏的证据：

- 测试命令输出（去掉用户名、绝对路径、令牌）；
- **安装包和发布产物**（如 `latest.json`、`*.sig`）的 SHA-256；
- 测试方法、处理行为与错误原因的脱敏摘要，不把开发机样本规模写成产品限制或性能承诺；
- 脱敏截图（不要包含完整目录、账号、密钥、真实图片 ID）。

不要提交：

- `.secrets/`、DPAPI 数据、更新私钥、GitHub token、认证来源；
- 真实游戏截图、整批输出、源图片或输出图片的 SHA-256/指纹；
- 真实文件名中的图片 ID、精确拍摄时间、EXIF/PNG 元数据；
- 本机图片库的文件数、分辨率分布、总容量、日期跨度及精确耗时；
- 机器型号、完整 OS build、主机名、用户名、`C:\Users\<name>` 或 UNC 路径；
- 未脱敏的失败清单、包含绝对路径的日志。

每个证据文件使用 `YYYY-MM-DD-<主题>.md`，并从 `docs/ACCEPTANCE.md` 链接。模板见 `2026-11-03-template.md`。提交前运行 `node scripts/scan-secrets.mjs`；发布前还应对 Git 历史执行同等的秘密/路径检查。
